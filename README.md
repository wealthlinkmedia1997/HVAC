# HVAC Marketing Center

Landing site for HVAC Marketing Center, a WealthLink Media company. GitHub Pages serves this repository from `main` at the site root.

Expected URL: https://wealthlinkmedia1997.github.io/HVAC/

`js/config.js` is intentionally blank: no Meta Pixel, no GA4, no Google Places key, no GHL webhook, no calendars, no Drive URLs, and no public phone or email. The form does not POST until a webhook is set. Booking pages show “Calendar not configured yet.” The explainer and reviews render visible placeholders.
